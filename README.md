# MS NAVIGATOR — Render + Neon

Закрытое веб-приложение с ролями администратора и пользователя. Данные, сессии и вложения хранятся в PostgreSQL Neon. Пароли сохраняются как PBKDF2-SHA256-хэши; одноразовый пароль активации нельзя использовать повторно.

## Развертывание

1. Создайте проект в Neon и скопируйте pooled connection string из окна **Connect**.
2. Загрузите эту папку в GitHub-репозиторий.
3. В Render выберите **New → Blueprint** и подключите репозиторий с `render.yaml`.
4. Введите секреты:
   - `DATABASE_URL` — строка подключения Neon с `sslmode=require`;
   - `MS_ADMIN_PASSWORD` — первоначальный пароль администратора (минимум 10 символов).
5. После успешного deploy откройте выданный адрес `*.onrender.com` и войдите под логином `admin` (или значением `MS_ADMIN_LOGIN`).
6. Сразу смените пароль в разделе **Кабинет → Пароль**.

Администратор создает одноразовый пароль в **Кабинет → Администрирование**. Новый пользователь открывает обычную форму входа, сам придумывает свободный логин и вводит выданный пароль. Отдельной кнопки регистрации нет.

## Локальный запуск

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export DATABASE_URL='postgresql://...neon.tech/neondb?sslmode=require'
export MS_ADMIN_PASSWORD='надежный-пароль'
python server.py
```

Откройте `http://127.0.0.1:8080`.
